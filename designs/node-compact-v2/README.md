# Routa 88 px 两行节点卡片 · V2 设计预览

本轮只制作设计预览，不修改正式源码与运行配置。与 V1 独立保存。

- `index.html`：完整交互设计稿，可直接打开。
- `01-card-comparison.png`：144 / 96 / 88 px 三种同宽卡片的对照。
- `02-nodes-page.png`：1440 × 900 完整节点页。
- `03-node-switch-dialog.png`：固定 960 × 720 px 的切换弹窗。
- `04-delay-states.png`：三档颜色、代理延迟命名及按需出现的测量提示。
- `05-dialog-empty.png`：搜索空态高度稳定的验证图。
- `validation.json`：浏览器中的尺寸与状态核对结果。
- `build_preview.py`：从上一版设计生成本版独立预览的脚本。

卡片外部尺寸高 88 px；示例对照宽 276 px。内边距包含边框为 12 px，顶部信息区高 36 px，底部元信息区高 20 px，中间间距 8 px。名称 14 px / 18 px 行高，最多两行；延迟 18 px，单位 12 px；协议与来源 12 px。右侧延迟区固定宽 74 px，更多操作在右下角，拥有独立点击目标。名称、来源和延迟均可按需查看完整提示。

节点页与弹窗共用排列及状态映射：≤300 ms 绿色，301–600 ms 橙色，>600 ms 红色；超时与连接失败为红色并有文字，未测试为灰色。代理卡片使用“当前代理延迟”，基础节点提示明确“节点延迟”。这套三档映射是本次 V2 设计提案，正式实现仍未变更。

动效可直接体验：悬停背景与边框 120 ms；选中背景、边框 120 ms；测量期间显示局部旋转标识，结果在 150 ms 内淡入；主动排序使用 180 ms 位移过渡；弹窗 160 ms 淡入并轻移 6 px。启用减少动态效果时关闭动画与过渡。排序只在主动开启后进行，测量结束后统一重排。

弹窗初始选中当前使用节点，确认按钮禁用；另选节点后显示“待切换”，当前实际使用节点仍单独标记。“⋯”菜单不会改变选择。确认只更新本地演示状态，关闭弹窗后代理延迟显示“待重测”；在代理卡片点击测延迟可演示恢复结果。所有动作均使用固定示例数据，没有外部 API、凭据或真实网络测试。

截图由 Chrome“Agent专用”连接渲染并导出。`?capture=1` 仅用于隐藏设计浏览条并导出 1440 × 900 画板；正常预览保留四个画板切换入口。

Pencil MCP 在本会话中不可用，因此以可编辑设计页面与 PNG 交付。正式代码保持不动，等待用户对密度和排列方式反馈。
