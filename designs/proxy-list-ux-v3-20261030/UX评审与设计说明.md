# 代理页 UX 优化

本轮延续用户已确认的方向：独立编辑列、全部操作属于对应行、取消底部当前选中操作栏。本目录是新的独立设计产物，不修改实际软件或覆盖此前设计。

## 发现的问题与调整

| 前版问题 | 本版处理 | 用户收益 |
| --- | --- | --- |
| 端口比代理名称更抢眼，身份信息分散 | 名称优先，协议与端口合并到第二行，并就近提供复制 | 扫描时先认代理，找入口时仍可直接读取 |
| 次级文字约 10 px，长时间阅读吃力 | 正文 14–15 px，辅助信息 11–12 px；行高从 68 增到 76 px | 提高文字可读性和控件点击范围 |
| 运行状态与开关同列，意图与结果易混淆 | 分别标注“运行状态”和“启用” | 能理解启用开关开启但代理启动失败的情况 |
| 端口冲突仍引导切换节点 | 失败原因就近展示，主操作改成“修改端口”，直接聚焦端口输入 | 操作能解决当前故障 |
| 正常状态重复大面积绿色底色 | 正常状态用绿色点与文字，异常保留浅红背景 | 异常更容易被发现 |
| 搜索和筛选是占位控件 | 原生 HTML 原型中实现多关键词搜索、状态筛选、清空及空态 | 能连续体验查找和恢复 |
| 空结果可能让列表高度变化 | 固定列表视口，表头和计数固定，内容区内部滚动 | 筛选、搜索和删除不会让主要操作跳动 |
| 已保存未生效与请求失败混为一谈 | 分别显示状态，保留当前实际节点、配置选择与重试 | 用户能判断是否已保存、是否已应用 |
| 停用代理选节点后被当成失败 | 停用时按钮为“保存选择”，说明下次启用生效 | 保存配置与运行切换的语义一致 |
| 搜索隐藏已选节点后仍可提交，选择不明显 | 固定底部始终显示“已选：节点名”与结果数量 | 用户确认提交内容，不依赖候选是否可见 |
| 窄窗口把整个 SVG 缩小，字和按钮随之变小 | 交互原型改为原生 HTML 表格；窄屏横向滚动，身份与编辑列固定 | 保持字号、点击目标与对应关系 |

## 行内操作

- 复制地址在协议与端口旁，支持系统剪贴板；失败时提供可手动复制的地址，不显示虚假成功。
- 手动策略直接提供“切换节点”。自动策略保留策略信息，通过编辑配置调整。
- 停用代理无当前实际去向，展示配置目标；可保存下次启用时的节点选择。
- 启停请求期间禁用本行相关操作，运行状态显示启用中或停用中；完成后才更新实际去向。
- 编辑入口始终可见，更多菜单保留测速、复制和删除；运行关闭或异常时禁用无意义的测速。
- 删除必须在更多菜单中发起，确认框明确代理名称和端口，默认聚焦取消。

## 搜索、筛选与反馈

搜索覆盖名称、端口、节点、策略和网卡；以空格分隔的关键词按 AND 匹配。清空搜索保留状态筛选；空态“清除筛选”同时清除搜索和状态条件。Ctrl/Cmd+K 聚焦搜索框。

状态改变后，如果代理不再属于当前筛选，通知明确“已移出当前筛选”，并提供“查看全部”。原型只更新对应数据行和计数，尽量保留当前键盘焦点。

菜单支持上下键、Home/End 和 Escape；候选节点支持箭头键选择。节点面板可取消，结束后焦点回到对应行的节点入口。编辑输入保留错误占位，端口冲突时定位到端口输入；外框高度和底部按钮位置保持不变。

## 节点切换状态

- 请求失败：不改变已保存选择及实际生效节点，保留候选草稿供重试。
- 已保存未生效：更新配置选择，实际节点保持旧值；列表就近显示待生效提示，面板提供“重试生效”。
- 成功：确认后更新配置和实际节点，以及相应延迟。
- 已关闭：只保存配置，不伪装成已建立连接，下次启用时使用配置。

面板固定 400 px 高，限制视口最大高度，标题、搜索、反馈区和底部动作固定，候选内部滚动。成功提示短暂淡入，不让整行闪烁；加载指示 800 ms 循环。响应系统“减少动态效果”设置。

- `01-ux-list.png`：高保真完整页面。
- `02-recoverable-switch.png`：已保存未生效时的恢复方案。
- 同名 SVG：可编辑源稿。
- `index.html`：可离线打开的原生 HTML 交互原型。功能包括搜索筛选、清空与空态、行内启停、节点选择和结果模拟、编辑校验、端口修复、新增、删除确认、更多菜单与地址复制。所有代理配置仅在内存中保存，关闭或刷新可恢复虚构初始数据。

预览不是软件实现。模拟的端口占用、保存和运行结果只用于验证 UX；后续实际实现应沿用项目校验与运行状态。静态图片已做视觉检查，交互使用本地 DOM 验证；未启动或控制浏览器。

只在本目录内创建产物，未修改 src、src-tauri、依赖、Git、实际配置或既有设计。没有使用子代理，没有安装依赖。当前无 Pencil MCP，因此继续使用 SVG / PNG 设计源稿。
