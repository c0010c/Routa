# Routa 代理页 V2 · 路线、状态、操作

这是独立设计产物。所有演示数据均为虚构；未修改软件实现、依赖、Git、实际配置或既有设计，未控制浏览器。

## 设计取舍

1. 入口到当前生效去向构成视觉中心，名称与状态用于识别。节点名称使用深色，蓝色主要服务于路径与操作。
2. 单代理卡片收敛为 872 × 216 px，上一版为 872 × 270 px。宽度有上限，不随窗口无限拉伸。窄屏在箭头处换行，性能区按组换行，操作保持可见。
3. 多代理采用 96 px 等高行，代理、路径、性能和操作分别对齐；过滤时固定标题、工具栏与底部计数，内部内容滚动。
4. 操作跟随对象：复制靠近端口，测速靠近延迟，切换节点靠近去向；编辑配置在次级区域，删除收进更多菜单。
5. 正常延迟、速率使用灰色与等宽数字，减少视觉竞争。异常使用颜色加文字，长名称省略且可悬停或聚焦查看完整内容。实时数值使用固定宽度，更新时不引起布局移动。
6. 分清配置与生效：规则分流展示“按规则分流”和默认去向；启动失败主路线展示“未生效”，配置目标保留在就近原因行。启用开关表达用户意图，状态文字表达实际运行结果。
7. 卡片和列表使用同一套信息语义与交互位置；用户手动选择视图后保留其偏好，增加代理不自动重排当前视图。

## 动效

- 悬停使用轻微背景变化，约 100–120 ms；键盘聚焦使用明确描边。
- 节点选择使用约 120 ms 的选中背景变化，保持文本与按钮位置。
- 切换中禁用提交按钮，保留当前生效节点。加载指示以 800 ms 循环，只在路径上使用轻微流动，不让整行闪烁或跳动。
- 只有运行状态确认成功后才替换节点，约 160 ms 交叉淡入，短暂高亮后恢复，2 秒成功反馈后淡出。
- 请求失败与已保存未生效分别说明。保留选择和弹窗，在预留反馈区提供重试。端口冲突等原因没有解决时，选择保存也不能表现成节点已生效。
- 弹窗固定高度、限制最大高度；标题、搜索、底部按钮固定，节点区内部滚动，预留反馈空间。
- 响应系统“减少动态效果”设置：关闭旋转、流动与过渡，保留文字和颜色反馈。HTML 原型会用静态图替换 GIF。
