Routa 亮色代理工作区 V3
日期：2026-10-30

设计方向
代理列表 + 固定高度配置工作区。
规则分流 / 统一转发 / 直连只决定当前端口内的流量处理。
系统代理与 TUN 接管单独设置，选择“统一转发”不会自动开启系统接管。
规则模式经用户确认，按每端口独立的域名 / IP 分流设计。

基础与高级
新建代理直接展示名称、本地端口、流量模式、代理去向、出站网卡、局域网开关。
规则模式额外展示分流方案及未匹配流量的去向。
高级默认折叠：代理协议、认证、接入网卡与共享方案。
应用、订阅、共享方案的新建同样将高级设置默认折叠。
接入范围通过开关和网卡名称选择，无需手输监听 IP。
出站网卡与允许接入的网卡分开，地址由原型根据选项自动展示。

主要可操作流程
新建 / 编辑 / 复制 / 删除代理；端口冲突检查；未保存修改处理。
三种流量模式切换；节点、策略组、共享方案选择；认证与局域网接入。
域名 / IPv4 规则验证；添加域名后缀与 CIDR 规则；优先级调整及默认去向。
四种策略；故障转移成员上移；手动选择组的当前节点选择。
系统接管独立选择端口和系统代理 / TUN 方式。
共享方案创建、编辑、删除及关联代理处理；应用与订阅示例流程。
空态、网卡断开和应用失败 / 重试。

布局验证
1100×800：基础网卡与局域网开关可见，底栏固定。
新建基础、高级展开、规则模式：弹窗高度均 720px，底栏位置一致。
节点选择全部 / 单个 / 空态：弹窗均 720px，列表内部滚动。
360×720：文档无横向溢出，配置底栏在视口内；弹窗高度 680px、距上下各 20px。
18 项交互验证通过，入口为 verify-interactions.mjs。

交付与边界
index.html 为无外部依赖的可点击版本；prototype.html 为可编辑源文件。
build-preview.mjs 校验脚本并同步独立预览与会话内版本。
原型不连接 mihomo，也不会修改真实系统代理或网卡。
域名 / IP 规则验证使用明确列出的示例规则进行本地推演；此为新增交互设计，不代表当前产品后端已经支持该能力。
