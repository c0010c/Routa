# 方向 C：路线工作台

第三版是一次独立的结构探索：左侧路线总览，右侧固定详情和操作面板。沿用 Routa 当前浅色 Windows 风格、蓝色强调色、184 px 左侧导航与现有图标。全部演示数据为虚构。

## 与第二版的区别

- 左侧的每条路线直接串起入口、策略和当前去向。单代理展示一条舒展路线，多代理缩成 116 px 的可选路线行。
- 右侧 328 px 面板围绕当前选择展示实时上传、下载、延迟、累计量及本地地址；最近 30 秒的小曲线用于深入观察所选代理。它是本轮发散提出的功能展示，非已实现能力。
- 点击“切换节点”后，右侧直接进入候选列表，不额外弹出居中弹窗。左侧路线保持可见，用户有持续的上下文。
- 启停、编辑配置和更多操作位于详情面板；删除收进更多菜单。手动选择代理的“切换节点”保持在路线行直接可达。
- 多代理路线下方保留简短延迟和双向速率，兼顾比较与聚焦查看。失败路线显示“未生效”，配置目标与原因单独说明。

## 交互与动效

- 选择路线：约 100–120 ms 的描边与背景变化，右侧内容约 140 ms 淡入；固定面板宽高，其他路线不移动。
- 切换节点：候选在同一面板框架内替换详情内容，头部、反馈区域和底部按钮位置固定，节点列表内部滚动。
- 提交：禁用提交按钮，800 ms 加载指示；左侧当前节点保持可见。
- 成功：确认实际生效后更新节点和延迟，短暂颜色高亮，2 秒成功反馈后消失，返回所选代理详情。
- 失败：保留候选、面板与路线，预留反馈区区分“请求失败”与“已保存未生效”。端口冲突未解决时不把配置当作已生效。
- 窄窗口建议将右侧面板收为固定抽屉；最大高度受视口限制，头尾固定，内容内部滚动。本 HTML 为桌面布局评审原型。
- 系统要求减少动态效果时关闭过渡、旋转与动画 GIF，以文字、颜色和静态图反馈。

## 适用性与取舍

此方向适合经常切换和观察少量至中等数量代理的用户。每行比纯表格占用更多高度，换取路线关系和持续可见的操作上下文；当代理数量很多时，第二版紧凑列表更节省空间。单代理仍保留留白，避免加入无关内容填充页面。
