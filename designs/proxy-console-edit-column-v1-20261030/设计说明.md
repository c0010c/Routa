# 代理终端：独立编辑列

用户要求在表格中增加一列用于编辑。本轮仅修改设计预览，创建设计独立目录，不覆盖上一轮方案、不修改软件源码、依赖、Git 或实际配置，未控制浏览器。

- 在“状态”右侧新增“编辑”列，每行常驻显示“编辑配置”。
- 编辑入口直接对应所在行，不要求先选中；点击编辑不改变当前选中项，防止底部操作目标意外变化。
- 窄幅收敛原列间距，保留原有字段、68 px 行高和固定底部动作区域。
- 底部移除重复编辑按钮，保留启停、切换节点、测速及更多菜单。
- 底部明确显示“当前选中：机场”，让其作用范围更容易理解。
- 删除仍位于更多菜单中。
- 编辑入口点击区域约 86 × 34 px，悬停浅蓝，键盘聚焦有清晰描边。

`01-edit-column.png` 是完整页面高保真预览，SVG 为可编辑源稿。`index.html` 可离线查看并点击每行编辑入口，弹出的固定尺寸演示框仅显示目标代理，用于验证操作归属，不包含本轮未请求的编辑表单。其他按钮为视觉占位。

当前会话没有 Pencil MCP，沿用 SVG / PNG 交付方式。生成只依赖现有图标和本机 Sharp，不安装依赖。
