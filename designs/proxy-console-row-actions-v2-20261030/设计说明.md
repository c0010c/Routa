# 代理列表：移除底部操作栏

用户明确希望移除整条“当前选中代理的操作栏”。本轮把操作全部归还给对应行，并取消“先选中，再操作”的交互模型。

- 去掉底部操作栏、当前选中信息、整行选中态。空白行区域不响应选择，底部只保留数量统计。
- 将策略并入当前去向的第二行，和出站网卡并排；失败原因在同一位置说明，避免增加列数。
- 手动选择代理的“切换节点”常驻在节点名称右侧，点击后就近打开固定尺寸候选面板。当前节点在确认生效前保持可见。
- 启停与实际运行状态并列，属于同一行。启用意图与实际状态分开表达；启用开着也可能启动失败。
- 保留独立“编辑”列，直接编辑对应代理。
- 每行更多菜单提供测速、复制地址、删除。全局“全部测速”仍在顶部。
- 正常行不用大面积高亮；悬停或聚焦只辅助定位按钮，避免暗示存在另一个当前选中对象。
- 68 px 行高不变。列表内容内部滚动，表头与计数保持固定；删除底部动作栏后，更多垂直空间用于列表。
- 节点候选面板固定高度；头部、反馈区和底部按钮不随搜索、失败改变位置，列表内部滚动，最大高度受视口限制。
- 在候选中禁用重复提交，成功后仅更新对应行，失败保留当前节点与选择并原位重试。减少动态效果时关闭旋转与过渡。

`index.html` 为离线交互演示，可体验每行编辑、节点切换、启停及更多菜单。数据虚构、变化仅保存在内存中，编辑入口仅展示目标归属，删除不移除示例数据，未连接实际软件。
