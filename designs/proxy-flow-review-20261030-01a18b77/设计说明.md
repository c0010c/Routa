## 设计依据

参考当前项目 `src/theme.ts`、`src/components/Layout.tsx`、`src/pages/Listeners.tsx`、`src/pages/ListenerNodeDialog.tsx` 和 `src/components/FormDialog.tsx`。使用项目的 Segoe UI / 微软雅黑字体、#0067c0 蓝色、#f3f3f3 背景、白色面板、184 px 导航和 MUI 图标。旧代理卡片宽约 360 px，至少 350 px 高。

单代理卡片宽度上限 872 px、高 270 px。宽度用于呈现“SOCKS5 :7893 → 新加坡01”的路径与临近操作。名称、运行状态、启停、更多操作构成头部；策略与网卡合成一行；性能和低频操作集中到底栏。宽屏保留留白，不添加占位装饰面板。窄屏建议在箭头处换行、性能区换行，卡片不横向溢出。

多代理列表以 96 px 等高行呈现。名称 / 状态、入口 → 去向、性能、操作分别对齐。手动选择策略直接提供“切换节点”；自动策略提供测速；直连提供复制地址。每行保留“编辑配置”、启停、更多菜单，删除收进更多菜单。启动失败时展示“端口被占用 · 未生效”；关闭时不显示旧的实时速率。高延迟仅用琥珀色提示，不误写为代理故障。

筛选与计数不随内容变化移动。卡片 / 列表支持显式选择；首次进入可按代理数选择默认视图，后续保留用户的视图选择，增加代理不自动打断当前视图。本原型中的场景切换用于比较两种设计。列表累计流量可放入性能信息的悬停或聚焦详情，避免增加一整列；长名称保持省略并支持查看完整内容。

## 节点切换

- 切换中：当前生效节点继续显示；提交按钮在原位禁用，800 ms 循环的旋转指示或箭头轻微流动，不让整行闪烁。
- 成功：确认运行状态后更新节点名，160 ms 淡入与短暂颜色高亮，2 秒后移除成功提示。保留键盘焦点。
- 请求失败：不关闭节点选择弹窗，在固定反馈区说明失败，保留候选节点供重试；当前生效节点不变。
- 已保存未生效：明确区分配置选择与当前生效节点，保留弹窗并提供重试；不提前把配置当作生效结果。
- 弹窗固定高度，标题、搜索和底部按钮固定；节点内容区内部滚动。反馈区域预留高度，失败不会推移按钮。小屏最大高度限制在视口内。
- 减少动态效果时关闭旋转、流动与淡入，以文字和颜色反馈。运行、关闭、失败均有文字标识，不依赖颜色。

## 范围

这是一套待评审的布局与交互方案。`index.html` 仅使用内存模拟状态，不连接内核、订阅或网络，也不读写软件实际配置。原型的删除确认仅演示菜单与弹窗，不移除示例行。

`generate.py` 和 `render.cjs` 用于重建本目录内的预览，读取项目已有图标及本机已有的 Sharp 渲染库；不会安装依赖。渲染不经过浏览器。
