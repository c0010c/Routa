# Routa 64 px 卡片比例微调 · V5

在已接受的约 224 × 64 px 单行卡片基础上检查信息层级。V5 已按用户确认实施到正式组件；本目录保留原设计预览，并增加正式组件的示例数据验收入口与截图，详见 [实施验收记录](implementation.md)。

| 元素 | V4 | V5 |
| --- | --- | --- |
| 名称 | 14 px / 600 | 保持 14 px / 600，单行省略 |
| 延迟数字 | 18 px / 600 | 16 px / 600 |
| 单位 ms | 12 px，跟随状态色 | 11 px / 400，次要文字色 |
| 协议、来源 | 12 px | 保持 12 px，协议标签使用轻浅灰底 |
| 更多图标 | 19 px | 16 px，点击范围保持 26 × 26 px |
| 小勾选 | 13 px | 12 px |
| 延迟列 | 64 px | 60 px，为名称增加 4 px |
| 失败/未测试/测量状态 | 12 px | 保持 12 px |

18 px 数字在 64 px 卡片内视觉权重偏高。16 px 保留等宽数字、右对齐、600 字重和状态色，让节点名称更容易首先被识别。单位不再与数值竞争。协议标签减轻边框和背景的存在感，保留辅助文字可读性。选中状态继续使用浅蓝底色、蓝色侧标和小勾选。

为检查边界，示例中包含 1280 ms 的四位数，其他正常、超时、连接失败、未测试、长名称和当前/待选状态继续保留。所有示例数据均为本地演示，不读取真实订阅，也不执行真实网络测试。

文件：

- `index.html`：可交互预览。
- `01-proportion-comparison.png`：18 / 16 px 延迟字号对照与元素尺寸。
- `02-nodes-page.png`：完整节点页。
- `03-node-switch-dialog.png`：切换节点弹窗。
- `validation.json`：实际尺寸、字号、边界及布局稳定检查。

沿用既有悬停、选择、测量、排序和弹窗动效，尊重减少动态效果设置。Pencil MCP 在本会话中不可用，交付可编辑设计页面及实际渲染 PNG。
