YAML 使用项目中已有的 yaml 解析器真实解析；规则验证使用原型内示例配置推演。

本轮调整
0. 取消、右上角关闭和 Esc 直接退出编辑，不出现“关闭当前编辑 / 放弃修改 / 继续编辑”的二次确认；未保存内容不提交。退出节点选择等子面板时仍返回父级表单。
1. 订阅改为独立卡片列表：每个订阅一张卡片，移除外层大列表面板。卡片展示节点数、URL、自动更新、上次更新和备用代理，提供更新、查看节点、编辑、删除。宽窗口并排，窄窗口单列。
2. 移除共享方案：代理配置直接保存节点、策略组和网卡；去向选择只保留单个节点与策略组。没有管理共享方案、保存为共享方案、引用共享方案等入口。
3. 订阅备用连接直接选择已有代理。删除该代理时同步处理订阅引用，并支持撤销。恢复旧原型状态时，把旧共享引用转成各代理的独立配置，保留连接去向和网卡。
4. 节点取消 Tab。订阅节点、手动节点和 Tailscale 在同一页面按自建分组折叠展示；没有有效分组的归入未分组。来源独立显示，不将订阅名当作自建分组。
5. 分组可包含所有来源的节点。一个节点可以属于多个自建分组；各组显示自己的成员，总数按唯一节点计数。未分组仅包含没有任何有效组的节点。
6. 支持逐组折叠、全部展开 / 折叠、全组搜索和延迟排序。搜索覆盖名称、来源、协议、分组名，自动展开匹配分组；清空搜索恢复之前的折叠状态。
7. 从订阅卡片进入节点页面时自动按该来源筛选，提供清除筛选入口。
8. 内核仅展示应用内置 mihomo 的身份与版本，移除内核路径输入和手动切换入口。保留内核启动 / 停止 / 重启、控制 API 端口、测速 URL、自动测速间隔和日志目录。

既有能力的保留与入口
概览：内核控制、上传 / 下载速率、累计流量、清零、代理状态、连接与日志。
代理：名称、端口、Mixed / HTTP / SOCKS5、启停、认证、局域网、接入网卡、出站网卡、复制地址、删除引用处理；规则分流 / 统一转发 / 直连；域名 / IPv4 CIDR 规则、代理 / 直连 / 阻断、未匹配去向和验证；单节点或四种策略组，支持引用整个订阅和自建分组。
系统接管：系统代理 / TUN / 指定应用，与端口流量模式分别设置。
订阅：新增、修改、更新、删除、自动更新间隔、备用代理、查看对应节点。
节点：搜索、延迟排序、测速、用于新代理；SOCKS5 / HTTP 表单、认证、UDP、TLS；YAML 错误反馈、解析预览、批量保存与嵌套参数；跨来源分组的新增、改名、成员修改与删除。
Tailscale：新建命名 → 登录 → 选择出口和验证；浏览器 / auth key、重新登录、链接复制、可用 / 离线 / 手动 / 无出口、失败重试；机器名、网卡、UDP、临时节点、分组；登录、出口、编辑等操作在同一节点行提供。
进程分流：组件启停与维护演示流程；进程 / EXE 路径、逐应用接入端口、启停和删除、故障阻断 / 直连、旧连接策略、退出后的全局策略、连接查看。
设置：开机启动、启动后连接、关闭到托盘、完整 / 简洁界面切换、控制端口、测速间隔 / URL、日志目录。
简洁界面：节点、端口、连接、接管范围与方式、流量；保留完整界面的代理和应用配置。
诊断：内核、默认代理、生效、端口冲突、系统代理 / TUN、服务与网卡状态、重新检查、日志。
共享方案与自定义内核路径根据本轮明确要求移除。
