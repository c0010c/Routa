# Routa 窄卡片与颜色选择 · V3 设计预览

按本轮反馈制作独立预览，正式业务源码、运行配置和 V1/V2 设计文件保持原样。

卡片对照宽度从 276 px 收到 224 px，减少约 19%，高度保持 88 px。完整节点页从四列调整为五列；切换弹窗使用四列，示例外框宽 1008 px、高 720 px。卡片按容器等分，实际宽度略有浮动。

名称继续使用 14 px / 18 px 行高、最多两行；协议与来源保持 12 px；延迟保持 18 px。延迟区从 74 px 收到 64 px，横向信息间距由 8 px 收到 6 px，卡片内边距仍为 12 px。来源过长省略，完整名称和测量信息在悬停与聚焦提示中出现。

选择使用浅蓝底 `#e5f1fc`、蓝色 3 px 侧标和小勾选，去掉此前较重的蓝色双描边。这样整张卡片更容易辨认。蓝色只表达选择，绿 / 橙 / 红继续表达延迟；当前使用与准备切换分别标明。底色在 120 ms 内过渡，卡片不位移。键盘焦点仍有独立外轮廓。

`index.html` 可直接打开，或通过本轮本地预览地址浏览。可体验选择、搜索、更多菜单、测量、排序、确认切换与待重测。数据和动作均为本地设计演示，不读取真实订阅，不调用 mihomo。

- `03-node-switch-dialog.png`：四列候选节点弹窗。
