# Routa v0.3.0

本次更新带来简洁版 / 完整版双模式界面、统一代理配置与 Windows 进程分流。

## 新功能

- **双模式界面**：首次启动可选择简洁版或完整版；设置中随时切换，共用已有配置。已有安装默认保留完整版。
- **统一代理配置**：集中管理 Mixed / HTTP / SOCKS5 端口、节点、策略组、直连出口、出站网卡和局域网访问；支持按域名或 IPv4 CIDR 设置端口分流规则。
- **三种接管方式**：支持 Windows 系统代理、指定应用进程分流与 TUN；系统代理记录并按所有权恢复原设置。
- **Windows 进程分流**：按 exe 完整路径指定 Mixed / SOCKS5 代理，支持故障与正常退出策略、行内切换代理，以及进程连接和流量查看。
- **资源与诊断**：整合订阅、手动节点与 Tailscale 管理，提供实际连接路径、内核日志、端口冲突和组件状态检查。

## 修复与改进

- 强化出口失效、出站网卡断开和过期代理配置时的阻断行为，避免流量意外直连。
- 改进进程分流服务的安装、升级、权限、配置确认、断线恢复与错误反馈。
- 完善节点和出口删除时的引用处理、配置保存反馈及流量统计。
- 加强便携包构建校验，记录并核对主程序、前端、服务与协议的构建信息。
- 提供独立的简体中文和英文使用指南。

## 下载

仅支持 **Windows x64**，界面为简体中文，内置 mihomo 内核。

- `routa_0.3.0_x64-setup.exe`：NSIS 安装程序。
- `routa_0.3.0_x64_en-US.msi`：MSI 安装包。
- `routa_0.3.0_x64_portable.zip`：解压后运行 `routa.exe`。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

## 升级与使用说明

- 升级前退出正在运行的 Routa。建议备份 `%APPDATA%\dev.routa\`；便携版备份程序旁的 `data` 目录，解压新版时保留该目录。
- 使用进程分流时，请将主程序与分流组件配套更新；当前协议版本为 3，组件安装或更新需要 UAC 授权。
- TUN 需要以管理员身份运行 Routa。系统代理仅影响遵循 Windows 代理设置的应用。
- 卸载 MSI 或删除便携版前，请先在应用内卸载进程分流组件；NSIS 卸载程序会请求授权清理组件。残留的阻断规则可能使指定程序无法联网。
- v0.1.0 的 `%APPDATA%\dev.mihomo-mapper\` 数据不会自动导入。

完整说明见 [中文使用指南](https://github.com/c0010c/Routa/blob/v0.3.0/README.zh-CN.md)和 [English guide](https://github.com/c0010c/Routa/blob/v0.3.0/README.md)。
